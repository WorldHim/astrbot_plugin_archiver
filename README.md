# astrbot_plugin_archiver

AstrBot 插件：语录！回复一条消息即可收录其发送人与内容，并可随机调用语录库中的语录。

# 功能

- **保存（入典）**：回复一条消息并发送 `/保存`，将该消息的发送人与内容（文本、图片，其他类型以占位符记录）存档进当前会话的语录库。**归属默认为回复消息的发送者；回复的内容为聊天记录（合并转发）时，归属取其中最后一条消息的发送者（以 QQ 号保存，避免群昵称变化影响）**，且**不展开为文本，而是以聊天记录（结构化子消息：发送人/文本/图片）原样保存**；拉取失败时回退为 `[转发消息]` 占位符。**`/保存` 可跟随 `@某人` 显式指定归属**（如 `/保存 @张三`，以 QQ 号保存，优先级高于默认归属，`@Bot` 唤醒自身会被排除）。
- **语录（来点典）**：发送 `/语录`，从当前会话语录库中随机抽取一条语录，以**聊天记录（合并转发消息）**的形式发回：普通语录以「发送人 + 内容」节点发送；**聊天记录语录保持聊天记录形态逐条发出，并在最后附一条收录信息**（收录人/收录时间/编号）。**支持抽取指定人的语录**：`/语录 @某人`（以 QQ 号精确匹配，`@Bot` 唤醒自身会被排除）或 `/语录 昵称`（昵称完整或包含匹配）；归属以 QQ 号保存，不受群昵称变化影响。
- **删除（删典）**：**回复语录消息（bot 发出的收录回执/语录回放）或被收录的原消息发送 `/删除`，即可删除该语录**。识别链（按序自动回退）：① 回复语录消息按发送时记录的消息映射精确定位（QQ 平台，不依赖拉取接口）→ ② 被回复消息回填内容中的编号（纯本地解析，文本回执与合并转发收录信息均嵌入编号）→ ③ 回复原消息按原消息 ID 定位 → ④ `get_forward_msg` 解析语录编号；也可直接 `/删除 <编号>` 按编号删除（编号见语录消息末尾收录信息）。

# 使用

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `/保存` | `/入典`、`/收录`、`/存档`、`/保存语录` | 回复一条消息发送，将其收录进本会话语录库 |
| `/语录` | `/随机语录` | 从本会话语录库中随机调用一条语录 |
| `/语录 @某人` | 同上 | 抽取指定归属人的语录（以 QQ 号精确匹配） |
| `/语录 昵称` | 同上 | 按昵称（完整或包含）匹配抽取指定人的语录 |
| `/删除` | `/删除语录` | **回复语录消息或被收录的原消息**发送，删除该语录 |
| `/删除 <编号>` | 同上 | 按编号删除语录（编号见语录消息末尾收录信息） |

> 指令受 AstrBot 唤醒前缀制约（默认 `/`），群聊中也可通过 `@Bot` 唤醒后发送。

示例：

```
用户A：今天天气真好（群里的某条消息）
用户B：（回复用户A的这条消息） /保存
Bot：[聊天记录] 张三：今天天气真好
                保存成功：已收录，本会话语录库共 1 条

用户C：/语录
Bot：[聊天记录] 张三：今天天气真好
                语录档案：收录人：用户B
                          收录时间：2025-09-14 12:00
                          编号：1fdf08f4
```

# 配置

在 AstrBot WebUI 的插件配置中可调整：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `use_forward` | `true` | 是否以聊天记录（合并转发消息）形式输出收录回执与语录；不支持合并转发的平台（如部分微信/Telegram 接入）可关闭，回退为文本输出 |
| `upload_permission` | `群员` | 上传(保存)权限：`群员`(所有人) / `管理员`(群管理员+群主+Bot管理员) / `群主`(群主+Bot管理员) / `Bot管理员`(仅Bot管理员) |
| `delete_permission` | `管理员` | 删除权限：级别同上 |
| `session_quote_limit` | `0` | 每个会话语录库的收录上限（条），超出后自动淘汰最早的语录；`0` 表示不限制 |
| `fallback_global` | `false` | 当前会话语录库为空时，是否从所有会话的语录库中随机抽取 |
| `image_compress_threshold_mb` | `2` | 收录图片超过该大小时自动压缩（MB），逐步重新编码并等比缩小直到达标；`0` 表示不压缩，始终保存原图 |

# 数据存储

- 语录库数据以 **SQLite 数据库**形式持久化保存在 `data/plugin_data/astrbot_plugin_archiver/quotes.db`，按会话（群聊/私聊）分组，开启 WAL 模式、事务性写入，为会话与归属（QQ 号）建索引。
- **自动迁移**：首次运行检测到旧版 `quotes.json` 时自动导入 SQLite，原文件重命名为 `quotes.json.migrated` 保留。
- 被收录的图片会**下载保存到本地** `data/plugin_data/astrbot_plugin_archiver/images/`，文件名取内容摘要（相同内容自动复用同一文件）；超过 `image_compress_threshold_mb` 的图片会自动压缩（带透明通道转 WebP、兜底 PNG，其余转 JPEG，必要时等比缩小），压缩后原图文件会被清理。动图（GIF 等）不做有损压缩以避免丢帧，原样保存。

# 说明

- 收录回执与语录调用默认以**聊天记录（合并转发消息）**形式发送：每条语录呈现为一条带有发送人昵称的转发消息节点，并附「语录档案」（收录人/收录时间）或「保存成功」信息节点。插件会按平台自动降级：仅 **aiocqhttp（QQ）** 与 **satori** 平台使用聊天记录（其余平台适配器会忽略合并转发组件导致输出无响应），自动回退为文本形式输出；也可在插件配置中通过 `use_forward` 总开关强制关闭。
- 收录时通过消息的引用（Reply）组件获取被回复消息的发送人与内容。各平台适配器对引用消息的回填程度不同：aiocqhttp（QQ）等平台可完整取回；若平台未回填引用内容，将回退到引用解析出的纯文本，仍无法读取时会提示收录失败。
- 被回复的内容为聊天记录（合并转发）时，**不展开为文本**，以聊天记录（结构化子消息列表：发送人、文本、图片）保存进语录库：`Node`/`Nodes` 直接从组件内嵌内容解析；`Forward` 在 aiocqhttp（QQ）平台通过 `get_forward_msg` 拉取子消息，子消息图片同样下载落盘（超过阈值自动压缩）。其他平台或拉取失败时回退为 `[转发消息]` 占位符。回放时聊天记录保持原样逐条发出，最后附一条收录信息（收录人/收录时间）。
- **权限管理**：`upload_permission` 与 `delete_permission` 分别控制上传(保存)与删除的权限，四级可选：`群员`(所有人)、`管理员`(群管理员+群主+Bot管理员)、`群主`(群主+Bot管理员)、`Bot管理员`(仅 Bot 管理员，即 AstrBot WebUI 中配置的管理员)。群管理员/群主通过平台接口实时查询；私聊消息无法查询群信息，按 Bot 管理员判定。
- 图片收录时若下载失败（如 URL 失效、网络异常），会回退为仅记录 URL，随机调用时再按 URL 发送。
- 随机调用时优先发送本地存档的图片，本地文件缺失（如被手动清理）时自动回退到 URL。
- 同一条消息（按消息 ID）在同一会话内不会被重复收录。
- 被收录消息中的表情、语音、视频、文件、合并转发等类型会分别以 `[表情]`、`[语音]`、`[视频]`、`[文件]`、`[转发消息]` 占位符记录。
